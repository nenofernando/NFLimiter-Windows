# NF Limiter UI assets

All items exist in editable SVG and transparent PNG. Assets are references; JUCE may draw them procedurally for perfect scaling.

- `logo_nf`: clickable reset-to-default-size region.
- `knob_gain`, `knob_ceiling`, `knob_small`: rotary controls.
- `power`, `bypass`, `toggle_on`: primary buttons.
- `preset_bar`: preset browser concept.
- `hamburger`: manuals/settings menu.
- `resize_handle`: lower-right resizing handle.
- `meter_input`, `meter_output`, `meter_gain_reduction`: meter styling.
- `clip_led`: overload indicator.

Palette: graphite `#080A0F`; input `#00E4FF/#16FF8B`; reduction `#FFD21C/#FF7918/#FF2525`; output `#9A55FF/#FF39D1`.
